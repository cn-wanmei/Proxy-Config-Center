# 架构说明 / Architecture Overview

## 中文

本仓库采用 **Core First** 设计理念。

- 所有规则与策略逻辑只在 `core/` 中维护一份
- 六个平台（Clash Meta / Clash / Loon / Egern / Stash / Shadowrocket）通过构建脚本从 Core 自动生成最终配置
- **节点由 Sub-Store 独立管理**，本仓库不包含任何节点订阅信息
- 修改 Core 后重新构建，即可同步更新所有平台配置

### 核心原则
1. 单一数据源（Single Source of Truth）
2. 平台只做渲染，不做逻辑
3. 易于长期维护与扩展

---

## English

This repository follows the **Core First** design principle.

- All rules and strategy logic are maintained only in the `core/` directory
- Configurations for six platforms (Clash Meta / Clash / Loon / Egern / Stash / Shadowrocket) are automatically generated from Core via build scripts
- **Nodes are managed independently via Sub-Store**. This repository contains no node subscription information
- After modifying Core, rebuild to update all platform configurations simultaneously

### Core Principles
1. Single Source of Truth
2. Platforms only render, they do not contain logic
3. Designed for long-term maintenance and easy extension
