# 命名规范 / Naming Conventions

## 中文

- 策略组名称统一使用**四字中文**（例如：广告拦截、人工智能、油管视频）
- 文件与目录名称使用小写字母 + 连字符（kebab-case）
- 核心逻辑只能放在 `core/`
- 平台能力与适配只能放在 `platforms/`
- 自动生成配置只能放在 `build/`，禁止手动修改
- Release Artifact 不作为 Core 源码的一部分维护
- 新客户端优先通过 `capabilities.yaml` + adapter 接入，不在 Core 中增加平台判断

## English

- Strategy group names use four Chinese characters where applicable
- Files and directories use lowercase kebab-case
- Core logic belongs only in `core/`
- Platform capability and adapters belong in `platforms/`
- Generated configs belong in `build/` and must not be edited manually
- Release artifacts are distribution outputs, not Core source
- New clients should be added through capability profiles and adapters, without Core platform branches
