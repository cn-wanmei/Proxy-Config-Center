# 命名规范 / Naming Conventions

## 中文

- 策略组名称统一使用**四字中文**（例如：广告拦截、人工智能、油管视频）
- 文件与目录名称使用小写字母 + 连字符（kebab-case）
- 核心逻辑只能放在 `core/` 目录
- 平台适配文件只能放在 `platforms/` 对应目录
- 自动生成的配置只能放在 `build/` 目录，禁止手动修改

---

## English

- Strategy group names must use **four Chinese characters** (e.g. 广告拦截, 人工智能, 油管视频)
- File and directory names use lowercase letters + hyphens (kebab-case)
- Core logic can only be placed in the `core/` directory
- Platform adapter files can only be placed in the corresponding `platforms/` directory
- Auto-generated configurations can only be placed in the `build/` directory and must not be edited manually
